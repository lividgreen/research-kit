# Closing a session

A session closes when a clone of the repository on another computer could continue from it.
That clone test rules out whatever does not travel: the agent's memory, the scratchpad, an untracked store, a subagent still running, a local tool's state.

1. **Inventory the conversation, turn by turn.**
   The items nobody flushed are the ones nobody listed: a ruling the owner gave in passing, an idea, a task whose shape is already there, a figure a report quoted.
   Each goes where it lives — a record, the log entry, the rules where the project keeps them — before anything else.
2. **Sweep by meaning.**
   Search the surfaces a reader sees for the claims this session made stale, by the claims' own words, not only the files the session already touched.
3. **The gates, by exit code.**
   The project's checks run and pass, read by their exit status.
4. **A commit with named paths, then the push as the backup.**
   A session that ends on a landing commit still runs the sweep: a clean tree says nothing about what the conversation still holds.

## The agent's memory

The agent's memory is per machine and fails the clone test, so nothing a continuation needs lives there alone.
It holds a fact about the process that no record owns — a trap paid for, a tool's behaviour, a preference of the owner — and never what the repository records, and never a tree-derived figure.
An incident goes to the log, the rule it earned to the skill or the instructions that own it, the agent's own trap to its memory; a lesson that holds for every project moves from the memory into a skill.
